# RVA Builds — Color Palette

> Extracted from the live Richmond Ed Fund brand (rps.fund) + `DESIGN.md`. Not invented.
> Coral is the dominant brand color; blue and purple are secondary/tertiary accents.

## Brand accents

| Token | Hex | RGB | Use |
|---|---|---|---|
| Coral (primary) | `#F15C2C` | 241, 92, 44 | Primary CTAs, key highlights, links, the icon fill |
| Coral hover | `#D8481F` | 216, 72, 31 | Hover / active state of coral elements |
| Blue | `#329FE6` | 50, 159, 230 | Secondary accent — **Employer** path, info |
| Purple | `#7A35AE` | 122, 53, 174 | Tertiary accent — **Candidate** path, badges |

## Surfaces

| Token | Hex | Use |
|---|---|---|
| Surface | `#FFFFFF` | Page background |
| Surface soft | `#F6F6F6` | Alternate section background |
| Surface tint | `#FDEDE7` | Light coral wash for callouts |

## Ink / text

| Token | Hex | Use |
|---|---|---|
| Ink | `#1A1A1A` | Body text (near-black, not pure black) |
| Ink muted | `#5A5A5A` | Secondary text, captions |
| Border | `#E4E4E4` | Hairlines, dividers, inputs |

## Status

| Token | Hex | Use |
|---|---|---|
| Success | `#1F8A4C` | Confirmation, valid input |
| Danger | `#C0392B` | Errors, destructive actions |

## Contrast rules (WCAG 2.1 AA)

- Coral `#F15C2C` on white ≈ **3.3:1** → passes AA for **large text / UI components only**, **not** small body text.
- Use coral for **buttons** (white text on coral, labels ≥18.66px bold) and **headings** — never small body copy.
- Body text always uses Ink `#1A1A1A` on white.
- Never rely on color alone to convey meaning (audience paths also carry labels + icons).

## Audience color cue

- **Candidate path** → Purple `#7A35AE`
- **Employer path** → Blue `#329FE6`
- **Shared primary CTA** → Coral `#F15C2C`
